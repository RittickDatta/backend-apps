
# Route Planner API

A Node.js, Express, and TypeScript backend for
graph-based route planning.

## Features

- Express REST API foundation
- TypeScript with strict type checking
- Health check endpoint
- Centralized error handling
- Automated API tests

## Requirements

- Node.js 20+
- npm

## Getting started

```bash
npm install
npm run dev
```

## Commands

| Command | Purpose |
|---|---|
| `npm run dev` | Development server |
| `npm run build` | Compile TypeScript |
| `npm start` | Run compiled server |
| `npm test` | Run automated tests |

## Endpoints

### GET /health

Returns service status and a timestamp.
